# TradeLingo Learn

Build TradeLingo, a polished dark-first mobile-first SaaS: “Learn trading. One decision at a time.” Deliver the actual working MVP requested: persistent auth and onboarding; dashboard; Duolingo-style learning path and fully populated first 3 worlds with 5+ interactive questions per lesson; instant feedback; XP, levels, streaks, achievements and progress; weak-topic practice; educational AI coach; simulated $10,000 paper trading with risk controls; risk calculator; trade journal; profile. Use Lovable Cloud/Postgres for persistence and implement the listed core database needs. Bottom nav Home / Learn / Practice / Coach / Profile. Include exactly this educational disclaimer: “TradeLingo is an educational platform and does not provide financial or investment advice.” Avoid profit claims, real-money trades, and casino/get-rich-quick styling. Make all buttons and core interactions work; prioritize Auth → Onboarding → Home → Learning Path → Lessons → XP/Streak → Progress → Practice → AI Coach → Paper Trading.
